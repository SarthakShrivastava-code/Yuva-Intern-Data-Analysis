### Week 1 
This report details the comprehensive data cleaning and preliminary exploratory data analysis (EDA) conducted as part of the Week 1 task for the Yuva Intern virtual internship program. The primary objective of this phase is to transform raw, messy data into a structured, highly refined format suitable for advanced statistical analysis and predictive modeling. For this task, the standard Titanic Passenger Survival dataset was selected. This dataset serves as an ideal foundation for data preprocessing exercises because it presents a variety of real-world complexities, including a diverse mix of continuous numerical features (such as passenger age and ticket fare) and categorical variables (such as gender and port of embarkation), alongside significant missing data in several key columns.

The methodology section of this report meticulously outlines the data cleaning pipeline implemented using R programming. To ensure the statistical integrity of the dataset, missing values were strategically handled: the 'Age' column was imputed using the median to prevent distributional skewing, while the 'Cabin' attribute was removed entirely due to an exceptionally high volume of missing entries. Furthermore, categorical variables were systematically encoded into numerical formats, converting text-based data into binary indicators to facilitate future algorithmic processing. Outlier detection was performed using boxplot visualizations, and extreme anomalies in the 'Fare' column were successfully capped utilizing the Interquartile Range (IQR) method. Finally, continuous variables were normalized using Z-score standardization to ensure comparability across different numerical scales.

Following the rigorous cleaning process, an exploratory data analysis was conducted to extract initial insights. By leveraging descriptive statistics and visual aids such as histograms, bar charts, and correlation matrices, several distinct patterns were uncovered. Most notably, the visualizations highlighted a significant disparity in survival rates based on gender, and the correlation analysis revealed key structural relationships between passenger class, fare, and survival likelihood. Ultimately, this report demonstrates a robust and professional approach to data preprocessing. The resulting dataset is now fully optimized, free of distorting anomalies, and completely prepared for deployment in subsequent machine learning models and data analytics tasks.

### Week 2
This report outlines the visual analytics and insight communication completed for the Week 2 task of the Yuva Intern virtual internship program. The primary objective of this phase was to develop dynamic, clear, and informative visualizations to communicate complex data patterns to a non-technical audience. For this analysis, the standard "diamonds" dataset from R's ggplot2 library was selected. This robust dataset contains the pricing and physical attributes of nearly 54,000 diamonds, providing an excellent foundation for exploring relationships between continuous variables, such as carat weight and price, alongside categorical features like cut quality and color grade.

The analytical methodology leveraged the R programming language and the ggplot2 visualization framework to create a diverse portfolio of business-focused graphs. A histogram was first utilized to map the overall distribution of diamond prices, revealing a heavily right-skewed consumer market dominated by lower-cost stones. To explore multivariate relationships, a scatter plot was designed to track the exponential positive correlation between a diamond's carat weight and its retail price, while simultaneously highlighting the premium commanded by superior cut qualities. Additionally, a categorical bar chart was implemented to assess inventory distribution, uncovering the counter-intuitive insight that the highest quality cuts ("Ideal") represent the largest volume of the market supply chain. Finally, box plots were generated to detect anomalies in price variance across different color grades, exposing a hidden market trend where diamonds with lower color grades frequently feature larger carat weights to compensate for their inferior coloring. Ultimately, this report successfully translates raw, multidimensional data into an accessible narrative, demonstrating the power of effective visualization in extracting actionable business intelligence.

### Week 3
This report details the comprehensive statistical analysis and predictive modeling pipeline developed for the Week 3 task of the Yuva Intern virtual internship program. The primary objective of this phase was to transition from foundational exploratory data analysis to advanced inferential statistics and machine learning classification. To achieve this, the widely recognized Breast Cancer Wisconsin (Diagnostic) dataset was utilized. This dataset contains highly detailed, continuous numerical features computed from digitized images of fine needle aspirates (FNA) of breast masses, alongside clear binary diagnostic outcomes classifying the tumors as either Malignant or Benign.

The analytical methodology commenced with rigorous hypothesis testing to establish statistical significance between the diagnostic categories. A Welch Two Sample t-test was conducted, definitively proving that malignant tumors exhibit a statistically significantly larger mean radius compared to benign tumors, yielding a near-zero p-value that strongly rejected the null hypothesis. Following this exploratory phase, the dataset was evaluated for multicollinearity using a correlation matrix before being systematically partitioned into training and testing subsets. A Logistic Regression classification model was subsequently developed and trained to predict tumor malignancy based on the established cellular features.

The final model demonstrated exceptional predictive capabilities on unseen testing data. Diagnostic evaluation via a confusion matrix revealed a high overall accuracy rate of 94.7%, characterized by strong sensitivity and specificity metrics, meaning the model successfully minimized both false positives and false negatives. Furthermore, the Receiver Operating Characteristic (ROC) curve analysis produced an Area Under the Curve (AUC) of 0.99, indicating an outstanding ability to distinguish between the two diagnostic classes. Ultimately, this report illustrates a robust, end-to-end data science workflow, successfully translating raw diagnostic data into a highly accurate, deployable predictive model.
